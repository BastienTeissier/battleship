# Battleship Game - AI Build playground

This repository aims to build a Battleship game using a coding agent.

## Stack

The aimed stack is as follows:
- Django (Python) for the backend
- HTMX, Alpine.js, Tailwind CSS for the frontend
- PostgreSQL for the database
- Docker for containerization
- GitHub Actions for CI/CD

## Steps

1. Setup the Django project and create a basic homepage for game management.
2. Implement user authentication and authorization.
3. Create the game logic for Battleship, including ship placement and turn-based attacks.
4. Design the database schema to store game state, user information, and game history.
5. Develop the frontend using HTMX and Alpine.js to create an interactive user interface.
6. Implement CI/CD pipelines using GitHub Actions for automated testing and deployment.
7. Test the application thoroughly to ensure it meets the specified requirements and is free of bugs.
